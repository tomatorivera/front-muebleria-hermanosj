# Frontend - Ecommerce Mueblería Hermanos Jota

## Introducción

Este repositorio corresponde al frontend del ecommerce para la Mueblería Hermanos Jota, construida de manera estática usando HTML, CSS y Javascript, y desplegada en Vercel.

En este repositorio se encuentra la primera versión corresponde a la entrega de los Sprints 1 y 2 del trayecto FullStack del ITBA.
